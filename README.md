# عرض مشروع محطة الوقود الذكية

عرض ويب عربي من 12 شريحة، مبني بـ Nuxt 4 ومهيأ للنشر على Vercel.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## التحكم أثناء العرض

- السهم الأيسر أو Space: الشريحة التالية.
- السهم الأيمن: الشريحة السابقة.
- `F`: ملء الشاشة.
- `O`: فهرس الشرائح.
- يدعم السحب يميناً ويساراً على الهاتف.

## النشر على Vercel

1. ارفع هذا المجلد إلى مستودع GitHub.
2. من Vercel اختر **Add New Project** ثم المستودع.
3. سيكتشف Vercel مشروع Nuxt تلقائياً؛ اترك أوامر البناء الافتراضية.
4. اضغط **Deploy**.

لا يحتاج المشروع إلى متغيرات بيئة أو قاعدة بيانات.
